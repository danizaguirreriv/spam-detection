# Enron-Spam data (not included)

The email data file is about 52 MB, so it is not stored in this repository.

Download `enron_spam_data.zip` from
https://github.com/MWiechmann/enron_spam_data (file `enron_spam_data.zip`),
unzip it, and put `enron_spam_data.csv` in this folder (`data/enron/`).

It is a single-file copy of the Enron-Spam corpus by Metsis, Androutsopoulos & Paliouras (2006).
The original files are available from the authors' pages (see the main README for the reference).
